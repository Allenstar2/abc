# LDO 專題架構研究（0.18 µm CMOS，大學部專題）

這個目錄是一次自主研究的產出。入口：

- `REPORT.md` — 最終報告（完成後）
- `STATE.md` — 目前進度；`LOG.md` — 時間記錄；`DECISIONS.md` — 假設與決定
- `literature.csv` — 文獻清單（含全文取得狀態）
- `sim/` — netlist、腳本、結果、圖；`sim/run_all.sh` 一鍵重跑
- 模型出處：`sim/models/MODEL_ATTRIBUTION.md`（PTM 180nm，CC BY 4.0 collection）

證據標註：[M] 論文實測、[S] 論文模擬、[D] 推導、[X] 本次模擬、[H] 假設或推測。
